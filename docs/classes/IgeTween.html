Class IgeTween

Creates a new tween instance. A tween instance automatically tweens properties over time. The engine must have the tweening component added before you can use IgeTween. You can do this by calling ige.uses("tweening"); before your call to ige.init().

All the actual tweening functionality is calculated and executed in the IgeTweenController (ige.tweening).

Example

Tween an entity's position
     const entity = new IgeEntity();
     new IgeTween(entity._translate)
         .properties({
             x: 500
         })
         .duration(5000) // 5 seconds
         .start();

  • repeatMode(val: IgeTweenRepeatMode, count?: number): this

    Gets / sets the repeat mode for the tween. If the mode is set to 1 the tween will repeat from the first step.
