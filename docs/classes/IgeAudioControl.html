Class IgeAudioControl

Handles controlling an audio source. You can use an instance of IgeAudioControl to start or stop playback of audio, but usually you would do this directly via ige.audio.play() or by using an IgeAudioEntity to allow streaming and further manipulation.

deferEmit

  • deferEmit(eventName: string, ...data: any[]): IgeAudioControl

    Queues an event to be fired. This has automatic de-bouncing so that any events of the same type that occur within 100 milliseconds of a previous one will all be wrapped into a single emit rather than emitting tons of events for lots of chained inserts etc. Only the data from the last de-bounced event will be emitted.

    Parameters

    • eventName: string

      The name of the event to emit.

    • ...data: any[]

      Optional arguments to emit with the event.

    Returns IgeAudioControl

    The emitter instance.

emit

  • emit(eventName: string, ...data: any[]): IgeEventReturnFlag

    Emit an event by name.

    Parameters

    • eventName: string

      The name of the event to emit.

    • ...data: any[]

      The arguments to send to any listening methods. If you are sending multiple arguments, separate them with a comma so that they are received by the function as separate arguments.

    Returns IgeEventReturnFlag

    Example

    #Emit an Event
        // Emit the event named "hello"
        myEntity.emit('hello');

    Example

    #Emit an Event With Data Object
        // Emit the event named "hello"
        myEntity.emit('hello', {moo: true});

    Example

    #Emit an Event With Multiple Data Values
        // Emit the event named "hello"
        myEntity.emit('hello', {moo: true}, 'someString');

    Example

    #Listen for Event Data
        // Set a listener to listen for the data (multiple values emitted
        // from an event are passed as function arguments)
        myEntity.on('hello', function (arg1, arg2) {
            console.log(arg1, arg2);
        }

        // Emit the event named "hello"
        myEntity.emit('hello', 'data1', 'data2');

        // The console output is:
        //    data1, data2

overwrite

  • overwrite(
        eventName: string,
        id: string,
        listener: IgeEventListenerCallback,
    ): this

    Overwrites any previous event listeners so that if the event fires, only the listener you pass will be called. If you pass an id along with the listener, only listeners for the id will be overwritten. This is similar to calling .off(eventName) then on(eventName, listener) since off(eventName) will cancel any previous event listeners for the passed event name.

    Parameters

    • eventName: string

      The name of the event to listen for.

    • id: string

      The id to match against.

    • listener: IgeEventListenerCallback

      The method to call when the event is fired.
