drawBounds

  • drawBounds(val?: boolean, recursive?: boolean): boolean | Ige

    Gets / sets the boolean flag determining if this object should have its bounds drawn when the bounds for all objects are being drawn. In order for bounds to be drawn the viewport the object is being drawn to must also have draw bounds enabled.

    Parameters

    • Optionalval: boolean
    • recursive: boolean = true

    Returns boolean | Ige

    Example

    #Enable draw bounds
        var entity = new IgeEntity();
        entity.drawBounds(true);

    Example

    #Disable draw bounds
        var entity = new IgeEntity();
        entity.drawBounds(false);

    Example

    #Get the current flag value
        console.log(entity.drawBounds());
