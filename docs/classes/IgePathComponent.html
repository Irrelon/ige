Class IgePathComponent

Handles entity path traversal. This component is supposed to be added to individual entities wishing to traverse paths. When added to an entity the component will add a behaviour to the entity that is called each update() and will operate to move the entity along a defined path.

dynamic

  • dynamic(enable?: boolean): boolean | IgePathComponent

    Gets / sets the dynamic mode enabled flag. If dynamic mode is enabled then at the end of every path point (reaching a point along the path) the pathfinder will evaluate the path by looking ahead and seeing if the path has changed (the points along the path have now been marked as cannot path on). If any point along the path up to the look-ahead value has been blocked, the path will auto re-calculate to avoid the new block.

    For dynamic mode to work you need to supply a pathfinder instance by calling .finder(), a point checker method by calling .pointChecker() and the number of look-ahead steps by calling .lookAheadSteps(). See the doc for those methods for usage and required arguments.

    Parameters

    • Optionalenable: boolean

      If set to true, enables dynamic mode.

    Returns boolean | IgePathComponent

    • Defined in src/engine/components/IgePathComponent.ts:127
