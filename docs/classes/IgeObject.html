  • streamCreateInitialData(): any

    Override this method if your entity should send arbitrary data through to the client when it is being created on the client for the first time through the network stream. The array will be received on the client via the onStreamCreateInitialData() event handler directly after being instantiated. The data is wrapped into the initial _igeStreamCreate network message sent from the server so the order of execution on receipt is:

    	constructor()
	id()
	mount()
